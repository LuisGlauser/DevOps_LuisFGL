# Notas da Aula

Durante a aula, foi abordado o conceito de configuração e sua importância no contexto de desenvolvimento de software.

Também foi revisado o projeto anterior, no qual foi criado um projeto do tipo "Vanilla". A partir disso, foi discutido o uso do Node.js e sua versão semântica, destacando a relevância do versionamento para garantir compatibilidade e organização no desenvolvimento.

Na sequência, a turma iniciou a criação de um projeto em React por meio do terminal (bash), com foco na estrutura inicial da aplicação. Foi demonstrado o uso de uma landing page no GitHub e a necessidade de utilizar um template disponível no próprio GitHub, configurá-lo corretamente e publicá-lo na plataforma Vercel.

Essas atividades têm como objetivo aplicar na prática os conceitos de configuração, versionamento e deploy de aplicações web.
